
# EventEase - Smart Event & Ticket Booking System

A modern event booking platform built using the MERN stack.

## Features

- Browse upcoming events
- Book event tickets
- QR code digital tickets
- User authentication
- Organizer dashboard
- Event management
- Ticket sales analytics

## Technologies

- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- JWT Authentication
